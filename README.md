# .github

Org-level defaults for the [Celados](https://github.com/celados) organization.

- [`profile/README.md`](./profile/README.md) — renders as the public org profile at
  [github.com/celados](https://github.com/celados).
- [`assets/`](./assets) — brand assets referenced by the profile.

Community-health defaults (issue templates, `CODE_OF_CONDUCT`, `CONTRIBUTING`,
`SECURITY.md`) get added here as the org's repos grow.
